# Concept of the Fork 
- Fork is the system call that creates a new peocess by copying the current one . 
- Before fork() you have one process. After it you have two near identical one is parent and other is child . 
- The child get the copy of the parents. i.e memory(code,data,stack,heap),open file descriptors.CPU registers,including the program counter ,meaning it is the in the code .
- So child doesn't start at the main .It start right after the fork() call
- On failure it return -1 which means no child created .

- The copies are independent.After fork changing a variable in one process does not affect the other . They have separate memory . 
- On performace details Copying all of the process memoery everytime would be slow . Real kernels use copy-on-write:parent and child share the same memory pages until one of them writes and only then is that page copied .

- exit(0) means Sucess everyhing is fine 
- non-zero means soemthing went wrong
